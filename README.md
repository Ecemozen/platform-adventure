==================================================
PLATFORM ADVENTURE - GAME DOCUMENTATION
==================================================

1. PROJECT OVERVIEW
-------------------
This project is a 2D side-scrolling platformer game created using Pygame Zero.
It features custom Object-Oriented Programming (OOP) classes, sprite animations,
patrolling enemies, sound effects, background music, and full game state logic
(Menu, Playing, Win, Lose).

2. REQUIREMENTS & DEPENDENCIES
------------------------------
- Python 3.x
- Pygame Zero (pgzero)
- Standard Python Libraries: math, random
- Pygame Modules: pygame.Rect, pygame.mixer

3. HOW TO RUN THE GAME
----------------------
Open your terminal/command prompt in the project root directory and run:

    pgzrun game.py

4. CONTROLS
-----------
- Left Arrow / Right Arrow : Move Player left/right
- Spacebar                  : Jump
- Mouse Left Click          : Interact with Menu and Game End buttons
